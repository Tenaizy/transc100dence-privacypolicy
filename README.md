<h2 style="font-size:16px;font-weight:700;color:#fff;letter-spacing:2px;text-align:center;margin-bottom:6px;">Politique de Confidentialité</h2>
<div class="date">Dernière mise à jour : Juin 2026</div>

<div class="section">
  <div class="section-title">1. Application</div>
  <p>TRANSC100DENCE est une application mobile de développement personnel, de suivi d'habitudes et de gestion budgétaire personnelle, développée par Tenaizy Duverger.</p>
</div>

<div class="section">
  <div class="section-title">2. Données collectées</div>
  <p>L'application fonctionne entièrement hors ligne. Aucune donnée personnelle n'est transmise à des serveurs externes. Toutes les données (habitudes, budget, historique) sont stockées localement sur votre appareil via le stockage local du navigateur (localStorage).</p>
</div>

<div class="section">
  <div class="section-title">3. Utilisation des données</div>
  <p>Vos données ne sont utilisées que pour le fonctionnement de l'application sur votre appareil. Elles ne sont ni vendues, ni partagées, ni transmises à des tiers.</p>
</div>

<div class="section">
  <div class="section-title">4. Sécurité</div>
  <p>L'accès à certaines fonctionnalités est protégé par un code d'accès unique. Ce code est stocké localement et n'est pas envoyé à des serveurs distants.</p>
</div>

<div class="section">
  <div class="section-title">5. Backup & Restauration</div>
  <p>La fonctionnalité de sauvegarde génère un fichier JSON contenant vos données. Ce fichier reste sous votre contrôle exclusif et n'est pas automatiquement partagé.</p>
</div>

<div class="section">
  <div class="section-title">6. Suppression des données</div>
  <p>Vous pouvez supprimer toutes vos données à tout moment depuis la section Réinitialisation de l'application, ou en effaçant les données de l'application depuis les paramètres Android.</p>
</div>

<div class="section">
  <div class="section-title">7. Contact</div>
  <p>Pour toute question concernant cette politique de confidentialité, contactez : <a href="mailto:tenaizyduverger@gmail.com">tenaizyduverger@gmail.com</a></p>
</div>
